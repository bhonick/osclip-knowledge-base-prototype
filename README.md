# OSCLIP Knowledge Base Prototype

This repository is a working prototype for the OSCLIP Project 1 knowledge base.

The project is developing a curated collection of open science and open scholarship resources for library and information professionals who support researchers, instructors, students, and institutions.

## Prototype status

This repository is temporarily hosted under Brendan Honick's GitHub account so the working group can review a concrete example while access to the official OSCLIP GitHub organization is being arranged.

The repository structure, categories, contribution process, and resource descriptions are drafts for group review. The repository may later be transferred to the official OSCLIP GitHub organization.

## Current phase

The internal resource-submission period has ended. The working group is now:

- Cleaning and reviewing the submitted resources
- Refining the resource categories
- Deciding what information should appear in the public knowledge base
- Establishing a manageable contribution and review process
- Preparing a prototype for the August 10, 2026 OSCLIP report-out

The public submission form will reopen when OSCLIP publishes its broader call for resources.
